# Contributing to FMGE Master

First off, thank you for considering contributing to FMGE Master! It's people like you that make this platform a powerful, free resource for medical students around the world.

## How to Contribute

### 1. Reporting Bugs
- Check the issue tracker to see if the bug has already been reported.
- If not, open a new issue. Include clear instructions on how to reproduce the bug, along with your OS, browser, and environment details.

### 2. Suggesting Enhancements
- Open a new issue detailing the feature you'd like to see.
- Explain *why* this feature would benefit FMGE candidates specifically. Remember our core principle: "FMGE Only."

### 3. Submitting Pull Requests
1. Fork the repository and create your branch from `main`.
2. Make your changes (ensure code passes linting: `npm run lint`).
3. If you've added new features, ensure they align with our "Free Forever" mandate (no payment gateways, no paywalls).
4. Issue a pull request outlining your changes and the problem it solves.

## Content Curation (Medical Students & Doctors)
If you are a medical professional wanting to contribute high-yield topics, notes, or verified questions:
- You do NOT need to code! You can submit content via our GitHub discussions or directly through the application's Admin Panel moderation queue (once deployed).
- All content must be original, public domain, or open-license. We strictly prohibit the upload of proprietary, copyrighted question banks or paid video course materials.

## Code of Conduct
Please note that this project is released with a [Contributor Code of Conduct](CODE_OF_CONDUCT.md). By participating in this project you agree to abide by its terms.
